## 1. 평가 지표 (Evaluation Metrics)

### F1 Score
* **정의**: Recall(재현율)과 Precision(정밀도)의 **조화평균**.
* **특징**: Recall과 Precision 값이 비슷할수록(균형 잡힐수록) F1 Score가 상승합니다.
* **수식**: 
```
  F1 = 2 × (Precision × Recall) / (Precision + Recall)
```
* 1에 가까울수록 좋음.

### ROC (Receiver Operating Characteristic)
* **정의**: TP Ratio(True Positive Rate)와 FP Ratio(False Positive Rate)를 축으로 그래프로 나타낸 것.
* **해석**: 실제로는 음성인 데이터를 양성으로 판정해서 틀린 비율 등을 고려함.

### 결정계수 (R², R-Square)
* **정의**: 독립변수(x)가 종속변수(y)를 어느 정도 설명하는지 나타내는 지표.
* **수식**:
```
  R² = SSR / SST = 1 - (SSE / SST)
```
* **용어 정의**:
  * **SST (총 제곱합)**: `Σ(yᵢ - ȳ)²`
  * **SSR (회귀 제곱합)**: `Σ(ŷᵢ - ȳ)²` (설명된 변동)
  * **SSE (오차 제곱합)**: `Σ(yᵢ - ŷᵢ)²` (설명 안 된 변동)
* **의미**: `SST = SSR + SSE`

## 2. 회귀 모델의 종류 (Regression Types)

* **다중회귀 (Multiple Regression)**
  * 서로 다른 독립 변수가 2개 이상일 때.
  * 기하학적 형태: **(초)평면 (Hyperplane)**

* **다항회귀 (Polynomial Regression)**
  * 하나의 변수가 복잡한 형태로 영향을 미칠 때.
  * 기하학적 형태: **곡선 (Curve)**

## 3. 규제 (Regularization) - Ridge & Lasso

모델의 과대적합(Overfitting)을 막기 위해 비용 함수(Cost Function)에 페널티 항을 추가하는 기법입니다.

### Ridge (L2 Regularization)
* **수식**:
```
  Cost = MSE + λ × Σ(wᵢ²)
```
* **특징**:
  * 가중치(w)가 커질수록 페널티가 기하급수적으로 증가하므로, 큰 가중치를 강하게 억제함.
  * 가중치를 0으로 만들지는 않음 (0에 가깝게 수렴).
  * **미분 가능**: 모든 구간에서 기울기가 부드럽게 줄어듦.
  * **기하학적 형태**: 원 형태 (`w₁² + w₂² = c`).
  * 오차 함수의 타원형 등고선이 원과 만날 때, 축 사이 어딘가에서 접한다. w 값이 작아지지만 0이 되지는 않는다.

### Lasso (L1 Regularization)
* **수식**:
```
  Cost = MSE + λ × Σ|wᵢ|
```
* **특징**:
  * 불필요한 가중치를 **0으로 만들어서 아예 변수 선택(Feature Selection) 효과**를 낸다.
  * 가중치가 0인 점에서 **미분 불가능** (뾰족함, Kink).
  * **기하학적 형태**: 마름모 형태 (`|w₁| + |w₂| = c`).
  * 타원형 등고선이 확장되다가 뾰족한 모서리 위에서 접할 확률이 매우 높다.
  * 해당 축을 제외한 다른 값은 0이 된다.

## 4. 의사결정나무 (Decision Tree)

### 불순도 (Impurity)
* **정의**: 해당 범주 안에 서로 다른 데이터가 얼마나 섞여 있는지를 나타낸다.
* 항상 불순도가 줄어드는 쪽으로 분기의 기준을 설정하는데, 이를 **정보 획득(Information Gain)**이라 한다.
* **Gini Index 수식**:
```
  Gini = 1 - Σ(pᵢ²)
```
  (pᵢ는 클래스 i의 비율)

### 정보 획득 (Information Gain)
* **수식**:
```
  Information Gain = Impurity(parent) - Σ(wᵢ × Impurity(childᵢ))
```
  (wᵢ는 각 자식 노드의 샘플 비율)

### 트리의 과대적합(Overfitting)을 막는 규제 (Hyperparameters)

불순도가 낮을수록 분기가 계속 생기면서 오버피팅이 안 생길 수가 없음. 따라서 아래 파라미터로 제어:

* `max_depth`: 트리의 최대 깊이 제한
* `min_sample_split`: 분할하기 위해 필요한 최소 샘플 수
* `min_sample_leaf`: 리프 노드에 있어야 할 최소 샘플 수
* `max_leaf_nodes`: 리프 노드의 최대 개수 제한

### Feature Importance (변수 중요도)
* 어떤 변수가 가장 중요한지 나타내는 값.
* 불순도를 가장 크게 감소시키는 변수.

### CART (Classification And Regression Tree) 알고리즘
* 불순도가 감소할수록 노드를 **분할**하는 알고리즘.
* 한 개의 노드가 2개의 트리를 만든다 (이진 트리).
* **주요 용어 (시각화 시)**:
  * `gini`: 불순도 점수
  * `samples`: 노드에 속하는 샘플의 수
  * `value`: 클래스별 샘플의 수
  * `class`: 예측 클래스
