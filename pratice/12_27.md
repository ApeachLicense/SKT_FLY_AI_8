# 로지스틱 회귀와 MLE (학습 노트 정리)

## 1. Odds와 Logit (Sigmoid 유도)

**Odds (승산)**
* 특정 사건이 발생할 확률($P$)과 발생하지 않을 확률($1-P$) 간의 비율.
* $$\text{Odds} = \frac{P}{1-P}$$

**Logit Function**
* Odds에 자연로그($\ln$)를 취한 값.
* $$\text{Logit}(P) = \ln \left( \frac{P}{1-P} \right) = w_1 x_1 + w_2 x_2 + b = z$$

**Sigmoid 함수 유도 과정**
위의 Logit 식을 $P$에 대해 정리하면, 출력값을 0과 1 사이의 확률로 변환해주는 **Sigmoid 함수**가 유도됩니다.

1. $$\frac{P}{1-P} = e^z$$
2. $$P = e^z (1 - P)$$
3. $$P(1 + e^z) = e^z$$
4. $$P = \frac{e^z}{1+e^z} = \frac{1}{1 + e^{-z}}$$

## 2. 확률(Probability) vs 우도(Likelihood)

* **(Q) 확률 (Probability):** $P(R|Q)$
    * **원인(Q)**을 이미 알고 있을 때, 그로 인해 발생할 **결과(R)**를 예측하는 것.
* **(R) 우도 (Likelihood):** $L(Q|R)$
    * **결과(R)**(데이터)가 관측되었을 때, 그 결과가 나오게 한 **원인(Q)**(파라미터)이 무엇인지 추정하는 것.

---

## 3. 최대우도추정 (Maximum Likelihood Estimation, MLE)

**우도 함수(Likelihood Function) 정의**
데이터 하나($x_i$)가 정답 $y_i$일 확률을 $P_i$라고 할 때, 이를 하나의 수식(베르누이 분포)으로 표현하면 다음과 같습니다.

$$P(y_i | x_i) = p_i^{y_i} (1-p_i)^{(1-y_i)}$$

$n$개의 모든 데이터가 독립적으로 관측될 전체 확률, 즉 우도 함수 $L(w)$는 개별 확률의 곱입니다.

$$L(w) = \prod_{i=1}^{n} p_i^{y_i} (1-p_i)^{(1-y_i)}$$

---

## 4. 로그 우도와 손실 함수 (Loss Function)

**로그 우도 함수 (Log-Likelihood)**
확률의 곱셈($\prod$)은 계산 시 값이 너무 작아져 언더플로우가 발생할 수 있습니다. 양변에 로그를 취해 곱셈을 덧셈($\sum$)으로 변환합니다.

$$\ln(L(w)) = \sum_{i=1}^{n} \left[ y_i \ln(p_i) + (1-y_i) \ln(1-p_i) \right]$$

**이진 교차 엔트로피 (Binary Cross-Entropy)**
머신러닝의 최적화는 값을 **최소화**하는 방향으로 수행됩니다. 우도를 최대화하는 것은 **음의 로그 우도**를 최소화하는 것과 같습니다.

$$J(w) = - \ln(L(w)) = - \sum_{i=1}^{n} \left( y^{(i)} \ln(p_i) + (1-y^{(i)}) \ln(1-p_i) \right)$$
