## 1. SGD (Stochastic Gradient Descent)

가장 기본이 되는 방법으로, 현재 위치의 기울기(Gradient) 반대 방향으로 일정 크기만큼 이동합니다.

**수식:**

```
θ(t+1) = θ(t) - η · ∇L(θ(t))
```

- `θ`: 파라미터
- `η`: 학습률
- `∇L`: 기울기

**특징:**
- 구현이 쉽고 직관적입니다.
- **단점:** 비등방성(Anisotropic) 함수(한쪽은 가파르고 한쪽은 완만한 지형)에서 탐색 경로가 지그재그로 심하게 진동하며 수렴 속도가 느립니다.

---

## 2. Momentum (관성)

물리학의 '운동량' 개념을 도입했습니다. 이전에 이동하던 방향(관성)을 유지하려는 성질을 이용합니다.

**수식:**

```
v(t) = γ · v(t-1) + η · ∇L(θ(t))
θ(t+1) = θ(t) - v(t)
```

- `v`: 속도
- `γ`: 마찰 계수 (보통 0.9)

**특징:**
- SGD의 진동을 억제하고, 관성을 이용해 국소 최적점(Local Minima)을 탈출할 가능성을 높여줍니다.
- **단점:** 멈춰야 할 지점에서도 관성 때문에 지나쳐버리는(Over-shooting) 경우가 발생합니다.

---

## 3. NAG (Nesterov Accelerated Gradient)

Momentum의 오버슈팅 문제를 해결하기 위해, **"관성으로 이동할 곳을 미리 가보고"** 그곳의 기울기를 사용합니다.

**수식:**

```
v(t) = γ · v(t-1) + η · ∇L(θ(t) - γ · v(t-1))
θ(t+1) = θ(t) - v(t)
```

- 기울기를 `θ(t)`가 아닌, 관성 이동 후 위치인 `θ(t) - γ · v(t-1)`에서 계산

**특징:**
- 목표 지점 근처에서 브레이크를 더 잘 밟아 안정적으로 수렴합니다.
- RNN 등에서 Momentum보다 성능이 좋은 경우가 많습니다.

---

## 4. AdaGrad (Adaptive Gradient)

변수(Parameter)마다 학습률을 다르게 적용합니다. 많이 변화한 변수는 학습률을 줄이고, 적게 변화한 변수는 학습률을 높입니다.

**수식:**

```
G(t) = G(t-1) + (∇L(θ(t)))²
θ(t+1) = θ(t) - (η / √(G(t) + ε)) · ∇L(θ(t))
```

- `G`: 기울기 제곱의 누적 합
- `ε`: 0으로 나눔 방지 (보통 1e-8)

**특징:**
- 희소한 데이터(Sparse Data) 처리에 강점이 있습니다.
- **단점:** 학습이 진행될수록 `G(t)`가 무한히 커져 학습률이 0에 수렴, **학습이 멈춰버리는 현상**이 발생합니다.

---

## 5. RMSProp (Root Mean Square Propagation)

AdaGrad의 "학습 조기 중단" 문제를 해결하기 위해 제안되었습니다. 모든 과거를 더하는 대신, **지수 이동 평균(EMA)**을 사용해 최근 기울기만 반영합니다.

**수식:**

```
G(t) = ρ · G(t-1) + (1 - ρ) · (∇L(θ(t)))²
θ(t+1) = θ(t) - (η / √(G(t) + ε)) · ∇L(θ(t))
```

- `ρ`: 감쇠율 (보통 0.9 ~ 0.99)

**특징:**
- 과거의 기울기 정보를 서서히 잊으므로 학습이 계속 진행될 수 있습니다.
- **단점:** 방향(Direction)을 제어하는 기능은 없어 진동이 남을 수 있습니다.

---

## 6. Adam (Adaptive Moment Estimation)

**Momentum(방향)**과 **RMSProp(보폭)**의 장점을 합친, 현재 가장 널리 쓰이는 알고리즘입니다.

**수식:**

1. **Momentum (m):**
```
m(t) = β₁ · m(t-1) + (1 - β₁) · ∇L(θ(t))
```

2. **RMSProp (v):**
```
v(t) = β₂ · v(t-1) + (1 - β₂) · (∇L(θ(t)))²
```

3. **Bias Correction:**
```
m̂(t) = m(t) / (1 - β₁ᵗ)
v̂(t) = v(t) / (1 - β₂ᵗ)
```

4. **Update:**
```
θ(t+1) = θ(t) - η · m̂(t) / (√v̂(t) + ε)
```

**특징:**
- 초기 경로 편향을 보정(Bias Correction)하여 학습 초기에도 안정적입니다.
- 하이퍼파라미터(`β₁=0.9, β₂=0.999, η=0.001`)가 튜닝 없이도 대부분의 문제에서 잘 작동합니다.

---

## 7. Nadam (Nesterov-accelerated Adam)

Adam에 **Nesterov Momentum**의 아이디어를 결합했습니다. "관성"이 적용된 기울기를 업데이트 식에 직접 반영합니다.

**수식 (구현용 변형 식):**

```
m(t) = β₁ · m(t-1) + (1 - β₁) · ∇L(θ(t))
v(t) = β₂ · v(t-1) + (1 - β₂) · (∇L(θ(t)))²

m̂(t) = m(t) / (1 - β₁ᵗ)
v̂(t) = v(t) / (1 - β₂ᵗ)

θ(t+1) = θ(t) - η / (√v̂(t) + ε) · (β₁ · m̂(t) + ((1 - β₁) / (1 - β₁ᵗ)) · ∇L(θ(t)))
```

- 기존 Adam의 `m̂(t)` 대신, 현재 기울기 항을 추가로 고려하여 업데이트

**특징:**
- Adam보다 수렴 속도가 빠르고, 최적점 근처에서 오버슈팅이 적어 더 안정적인 경우가 많습니다.
- 최근 딥러닝 연구에서 Adam의 강력한 대안으로 많이 사용됩니다.
